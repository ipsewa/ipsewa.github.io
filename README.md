# IP Sewa — GitHub Pages

A responsive, self-contained guide to trademark registration, patent registration, and industrial design protection in Nepal. The service links, wordmark, main calls to action, and resource directory connect directly to **https://ipsewa.com/**.

## Publish on GitHub Pages

1. Create or select the GitHub repository you want to use.
2. Upload `index.html` and `.nojekyll` to the root of its `main` branch. Put `index.html` directly in the repository root, rather than inside the ZIP's folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then click **Save**.
6. Open the published URL shown in the Pages settings once deployment finishes.

GitHub's official instructions: https://docs.github.com/en/pages/quickstart

The page works on both a user site (`https://USERNAME.github.io/`) and a project site (`https://USERNAME.github.io/REPOSITORY/`). There are no build commands, external assets, API keys, or package installations. All CSS and JavaScript are embedded in `index.html`; `.nojekyll` requests plain static publishing.

## Included

- Responsive page with keyboard-accessible navigation and a skip link.
- Trademark, patent, and industrial design service summaries.
- Five-stage trademark filing overview and the supplied educational article.
- Expandable FAQs.
- All ten supplied IP Sewa URLs, with individual and bulk copy buttons.
- Descriptive metadata, the ten supplied keywords, structured page information, and a site favicon.
- Clipboard fallback for browsers that restrict automatic copying.

## Edit

Open `index.html` in a text editor. Change the content in the HTML or the colors in the `:root` CSS variables. Open the file in a browser to preview it. Copy buttons use the browser clipboard when available and offer manual copying if permissions prevent it.

The connected services are provided on the main IP Sewa website. This GitHub page does not submit applications or access customer accounts. It uses ordinary HTTPS links to send visitors to the relevant IP Sewa pages.

No custom domain is configured. Keep `ipsewa.com` serving the main site. Add canonical and absolute sharing URLs only after your GitHub Pages address is known.
